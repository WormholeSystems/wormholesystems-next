# Background image

You can put a picture behind the map: a corp logo, a hand-drawn chain diagram, a
screenshot of the region, whatever helps you read the chain. It is yours alone. Nobody else
on the map sees it, and you can have a different one on every map.

## Setting one

Click the picture button in the map's bottom-right corner, next to the zoom controls. Drop
a file onto the box, or click it to pick one: a PNG, JPEG, GIF or WebP of up to 8 MiB. It
shows up behind the chain straight away, and stays with your account, so it follows you to
another browser or machine.

The same box swaps it for another file, and **Remove** takes it away and brings the plain
grid back. The map's settings page has the same controls under **Display**, if you would
rather set it there.

## How it sits

Once there is a picture, a second setting says how it behaves when you move around:

- **Moves with the map** paints it across the whole grid. It pans and zooms together with
  the systems, so a drawn diagram stays lined up with the nodes you placed over it.
- **Fills the panel** stretches it to the visible map panel and keeps it still while you
  pan and zoom. Better for a logo or a backdrop that should not move.

The grid lines still draw on top of it in custom placement. In automatic placement there
are no grid lines, only the picture.

## Guests

Somebody looking at the map through a share link has no settings of their own, so they see
the plain grid.
