# Ship size

A wormhole's **ship size** is the largest hull it will let through, set by the wormhole type itself. Unlike mass and lifetime it doesn't change as the hole ages — it's a fixed property of the hole. A new connection starts **Unknown**: nobody has said what fits yet, which is not the same as saying a battleship does.

| Status          | What fits                                                               |
| --------------- | ----------------------------------------------------------------------- |
| **Unknown**     | Nobody has read the hole yet. The line carries no size letter.          |
| **Frigate**     | Frigate-sized hulls only (frigates, destroyers, and similar).           |
| **Medium**      | Up to battlecruiser- and industrial-sized hulls.                        |
| **Large**       | Up to battleships.                                                      |
| **Extra Large** | Capital-class hulls — carriers, dreadnoughts, freighters, and the like. |

Identifying the signature sets the size for you and locks it, since the wormhole type says what fits. Anything you set by hand can be set back to **Unknown**.

Recording ship size stops someone bringing a hull that simply can't fit — and lets autopilot avoid routing a large ship through a frigate hole.
